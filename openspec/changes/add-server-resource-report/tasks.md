## 2. 系统、CPU 与内存采集

- [x] 2.1 实现系统概要采集，记录主机名、系统、内核、运行时间、虚拟化信息、CPU 核数、内存总量、报告时间和模块状态，对不可用项输出 `unknown`。
- [x] 2.2 基于 `/proc/stat` 实现系统 CPU 增量采样，并记录平均值、峰值、有效采样窗口和 1/5/15 分钟负载。
- [x] 2.3 基于 `/proc/<pid>` 实现进程 CPU 聚合排行，输出 PID、用户、命令、平均值、峰值和有效样本数，并容忍进程退出和权限不足。
- [x] 2.4 实现内存、缓存、可用内存和 Swap 采集，并按 RSS 生成进程内存排行，使用可用内存而非缓存量判断内存压力。

## 3. 文件系统与目录空间分析

- [x] 3.1 实现文件系统容量和 inode 采集，输出源设备、挂载点、文件系统类型、已用量、可用量和使用率。
- [x] 3.2 实现 `findmnt` 挂载发现与 `/proc/self/mountinfo` 回退解析，建立本地、远程/分布式、特殊/容器和保守排除的 FUSE 分类。
- [x] 3.3 实现扫描计划生成：父文件系统不跨挂载点，本地独立数据盘单独扫描，远程与特殊挂载不进入且不会重复计数。
- [x] 3.4 实现带最大深度、总超时、排行数量和自定义排除路径的目录空间扫描，按字节排序并保留所属文件系统与扫描根信息。
- [x] 3.5 在超时、权限不足、命令失败或用户中断时终止对应扫描子进程，保留安全的已完成结果并将范围标记为不完整。
- [x] 3.6 在报告数据中记录所有跳过挂载点的路径、类型和排除原因，并记录每个扫描任务的参数、耗时和完成状态。

## 4. 磁盘、网络与硬件采集

- [x] 4.1 基于 `/proc/diskstats` 实现块设备增量采样，计算读取/写入平均与峰值吞吐、读取/写入 IOPS，并区分父设备与分区。
- [x] 4.2 在 `iostat` 可用时解析等待、队列和利用率等增强指标，在工具缺失或输出不兼容时保留基础 I/O 数据并标记增强项未知。
- [x] 4.3 基于 sysfs 网卡计数器实现接收/发送平均与峰值速度、错误和丢包增量，并采集接口状态、地址、类型和默认路由。
- [x] 4.4 在 `ethtool` 可用时补充链路协商速率；对回环、物理、Bond、Bridge 和用户指定接口应用明确的选择与类型规则。
- [x] 4.5 实现可选基础硬件模块，采集 CPU 型号、块设备型号/类型/容量以及可获得的 SMART 和温度摘要，虚拟机不可用项标记为未知。
