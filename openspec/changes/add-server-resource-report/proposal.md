## Why

当前 VM 脚本库将进程、目录空间、磁盘 I/O 和性能测试拆分为多个独立脚本，运维人员无法按需一次生成包含资源排行、实时性能与问题结论的完整服务器报告。现有目录空间脚本也缺少远程挂载排除、扫描边界和超时保护，直接用于整机分析容易进入 NFS、SMB/CIFS 等远程目录并造成长时间扫描。

## What Changes

- 新增服务器资源分析报告脚本，并作为 VM“服务器状态检查”菜单的第一项；现有菜单项依次后移。
- 提供 `dialog` 复选菜单作为交互式模块选择，空格勾选或取消后回车确认，默认只勾选 CPU 和内存，让用户按需加入系统概要、磁盘、网络、硬件健康和主动性能测试等内容。
- 缺少 `dialog` 时自动安装，安装失败给出手动安装命令并回退到文本编号输入。
- 生成 CPU 与内存进程占用排行，并通过短时采样区分瞬时占用、平均占用和峰值占用。
- 生成文件系统容量、inode 和目录空间排行；扫描时自动识别并排除 NFS、NFS4、SMB/CIFS、SSHFS、Ceph、GlusterFS、rclone 等远程或分布式挂载，以及系统伪文件系统和容器 Overlay 挂载。
- 为目录扫描提供扫描根目录、排行数量、深度、超时和自定义排除目录控制，并在报告中列出被跳过的挂载点。
- 采集磁盘实时读取、写入、IOPS、等待时间和利用率，以及网卡实时收发速度、链路状态、错误和丢包。
- 将只读诊断与会主动制造负载的磁盘性能测试、外网测速分开；主动测试默认不执行，并在运行前要求明确确认。
- 根据可配置阈值输出严重、警告和提示三级分析结论，同时保留采集失败或工具缺失信息。
- 根据本次所选模块检查依赖工具并自动安装缺失软件；安装失败时继续可降级的采集，在终端及所有报告格式中记录失败原因和手动安装命令。
- 生成便于人工查看和后续程序消费的文本、JSON 与 HTML 报告，并在默认目录不可写时安全回退。

## Capabilities

### New Capabilities

- `server-resource-reporting`: 定义 VM/服务器资源报告的模块选择、资源采集与排行、远程挂载安全排除、主动测试保护、分析结论和多格式输出行为。

### Modified Capabilities

无。现有 `pve-hardware-reporting` 保持 PVE 硬件健康报告定位，不承载本次通用 VM 资源诊断需求。

## Impact

- VM 脚本菜单：`scripts/os_tool/vm/default/index__monitor.sh`。
- 新增 VM 资源报告脚本，预计位于 `scripts/os_tool/vm/default/`，并复用 `scripts/os_tool/tools.sh` 的 Python 下载运行入口。
- 运行时读取 Linux `/proc`、`/sys`、挂载表、进程、文件系统和网卡统计信息；部分增强指标依赖 `sysstat`、`iotop`、`ethtool`、`smartmontools`、`fio` 或测速工具。
- 目录扫描会产生读取负载；磁盘性能测试和外网测速会主动消耗磁盘或网络资源，因此需要显式选择和二次确认。
- 不改变现有监控脚本、面板 API、数据库结构或 PVE 报告行为。
