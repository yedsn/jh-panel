## MODIFIED Requirements

### Requirement: 批量操作支持批量删除管理记录
NFS 管理器 SHALL 在批量操作区提供经过数据安全确认的批量删除入口，并且批量删除只能移除插件管理记录，不得自动卸载挂载、修改 `/etc/fstab`、删除本地目录或删除远端数据。

#### Scenario: 用户发起批量删除
- **WHEN** 用户选择一个或多个挂载项并点击批量删除
- **THEN** 系统使用数据安全确认展示选择数量和挂载名称，并明确说明现有挂载和自动挂载配置不会被清理

#### Scenario: 用户取消批量删除
- **WHEN** 用户在批量删除确认中选择取消
- **THEN** 系统不删除任何管理记录且保持当前列表不变

#### Scenario: 用户确认批量删除
- **WHEN** 用户确认批量删除
- **THEN** 系统对所选 ID 去重，删除所有仍存在的管理记录，报告已删除与不存在的记录，并刷新挂载列表

#### Scenario: 删除包含运行中或自动挂载条目的选择
- **WHEN** 已选记录中存在当前已挂载或已配置自动挂载的条目
- **THEN** 系统仅删除管理记录，不执行卸载命令、不修改 `/etc/fstab` 且不删除挂载目录

#### Scenario: 批量删除请求没有有效选择
- **WHEN** 批量删除接口收到空 ID 列表
- **THEN** 系统拒绝请求且不删除任何记录
